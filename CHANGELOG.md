# Changelog

All notable changes to `DummyJSONClient` will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Until version 1.0.0, minor releases may include breaking changes to the public API.

## [0.1.0] - 2026-11-08

### Added

- Typed async APIs for products, users, carts, posts, comments, todos, quotes,
  recipes, authentication, and DummyJSON utilities.
- Configurable HTTP transport and deterministic fixture-based tests.
- Token storage, authenticated requests, token refresh, and logout support.
- Support for macOS 12+, iOS and tvOS 15+, watchOS 8+, and visionOS 1+.
